## 2. 冲突升级链（九步）

```text
序章：火箭发射失败 → 佃背锅离开宇宙机构 → 回老家继承工厂
第1章：京浜机械撤单（断粮）→ 中岛专利诉讼 90 亿（围猎）→ 白水银行拒绝融资（收伞）
第2章：帝国重工视角（财前看到佃的技术价值）
第3章：专利授权谈判 → 帝国重工提出收购（诱惑）
第4章：佃内部动摇 → 唐木田（理性派）vs 佃（梦想派）
第5章：佃宣言"这不是钱的问题，是尊严的问题"（拒绝收购）
第6章：品质评估测试（技术证明战）
第7章：燃烧试验通过 → 发射成功
尾声：胜利 = 新商机开启
```

**与半泽的区别：** 半泽是"被推入坑→取证→翻盘"；下町是"被逼入绝境→拒绝轻松路→用技术证明自己"。半泽的武器是证据链，下町的武器是产品品质。半泽打的是"人"（对手是腐败的银行员），下町打的是"技术"（对手是不信你的评估官）。

## 3. 文风蒸馏

### 3.1 对话占比：56.4%

比半泽（60.1%）略低，但差异不大。**两本书都是"对话驱动"而非"叙述驱动"。**

下町的特殊之处：**对话承担技术解释功能。** 半泽的对话是权力博弈，下町的对话是技术交锋（"这个阀门的公差是多少""这个专利的应用范围是什么"）。读者通过对话学习行业知识，不觉得被灌输。

## 6. 下町特有的写作技巧

### 6.1 技术解释不觉得枯燥的三个方法

1. **通过对话而非叙述**：让不懂技术的人问，让懂的人答，读者跟着学。
2. **把技术变成赌注**：不是"阀门公差多少微米"（没人关心），而是"这个公差不过关，火箭就上不了天"（生死攸关）。
3. **用对比呈现**：大工厂的"制式化" vs 小工厂的"学术气息"，让读者自然理解为什么小厂能做出来。

### 6.2 双视角交替

下町在奇数章用佃视角，偶数章插入帝国重工视角（第二章是财前的视角）。这让读者同时看到"弱者的焦虑"和"强者的傲慢"，制造期待：财前什么时候会倒向佃？

半泽不用这个手法——半泽永远从半泽视角出发，对手是"被侦破"的对象。下町的对手最终变成了客户/盟友，所以需要提前给对手"人味"。

### 6.3 编号小节的功能

每章 6-13 个编号小节。每个小节是一个完整的"动作-反应"单元：

```text
小节 N：外部事件（银行拒绝/对手出招/测试开始）
小节 N+1：内部反应（争论/决策/情绪）
小节 N+2：新一轮外部事件
```

这种结构让读者每次都想"再看一小节就睡"，跟短剧的"下一集钩子"逻辑一样。

## 7. 仿写模板

### 7.1 一句话前提

```text
[小主体] 掌握 [核心专利/技术]，
却被 [大企业] 用 [收购/诉讼/撤单] 逼入 [可量化绝境]，
主角拒绝轻松的出路（卖专利/卖公司），
必须在 [评估期限] 内用 [产品品质] 证明自己。
```

### 7.2 章节骨架（基于下町）

```text
序章（2K）：一场失败/创伤（建立身份）
第1章（38K）：三重打击（撤单+诉讼+银行收伞）
第2章（24K）：对手视角（让读者看到敌人也是人）
第3章（29K）：诱惑出现（轻松出路 vs 艰难正路）
第4章（12K）：内心摇摆（内部争论）
第5章（17K）：宣言时刻（拒绝诱惑）
第6章（12K）：技术验证（品质测试）
第7章（16K）：最终考验（发射/生产/交付）
尾声（2K）：胜利 + 新挑战
```

### 7.3 佃式宣言模板

```text
"这不是 [钱/利益/风险] 的问题。
这是 [身为 XX 的尊严/信念/梦想] 的问题。"

（然后解释为什么——用产品说话，不用口号说话。）
```

### 7.4 下町 vs 半泽：选哪个模板？

| 场景 | 用哪个 |
|---|---|
| 写银行/金融/资本运作 | 半泽模板 |
| 写工厂/技术/制造业 | 下町模板 |
| 写权力斗争/派阀/内部告发 | 半泽 |
| 写品质验证/测试/验收 | 下町 |
| 主角是复仇者 | 半泽 |
| 主角是匠人 | 下町 |
